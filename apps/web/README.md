# ODD RAVEN Web App

Next.js PWA scaffold for the customer app and staff operations screens.

## Phase 1 Screens

- Customer dashboard.
- New order.
- My orders.
- Messages.
- Design library.
- Approval screen.
- Payment status.
- Support.
- Staff order dashboard.

## Install

Node.js is not currently installed on this machine. After installing Node.js LTS:

```powershell
npm install
npm run dev
```
