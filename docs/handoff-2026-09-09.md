## Transfer to the Next System

Clone `https://github.com/gurumoorthyhi-gif/OR-CUSTOMER-CONNECT.git`, or pull `main` in an existing clean checkout. Do not overwrite uncommitted work on the destination machine.

From the repository root in PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r services\api\requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
npm --prefix apps\web ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
```

Set local secrets and integration credentials on the destination separately. Configure CORS for port 3011 and ERP for port 8002 as documented in `CODEX_STARTUP.md`. The example configuration now matches those ports. Pixelcut is deliberately disabled in the example; enable it only with authorized external processing access.

Double-click `Start App.cmd`, or run `npm run web:dev`. The launcher starts/reuses the API on 8000 first, then the frontend on 3011. It waits for responses before opening the new-order page. Start ERP separately when required. The launcher does not install dependencies or configure a Windows startup task, and a browser bookmark alone cannot launch the backend.
