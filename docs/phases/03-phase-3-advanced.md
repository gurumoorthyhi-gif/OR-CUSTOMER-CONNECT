# Phase 3 - Advanced Platform

## Outcome

The platform adds intelligence, prediction, dealer workflows, deeper reporting, and optional native app expansion.

## Features

- AI artwork cleanup suggestions.
- Background removal, upscale, trim, resize, white choke, and mirror support where approved.
- Smart machine and supplier assignment.
- CRM segmentation and follow-up automation.
- Inactivity and volume-drop alerts.
- Inventory consumption prediction.
- Maintenance alerts by meters, hours, and days.
- Dealer portal with special pricing, multiple addresses, statements, and credit.
- Advanced reports for margin, cost per meter, retention, LTV, complaints, courier loss, supplier comparison, and machine performance.
- Optional native mobile app if PWA limits become real.

## Acceptance Criteria

- Advanced features use customer-authorized data only.
- Automation is explainable and staff can override it.
- Reports reconcile with orders, invoices, payments, production, and waste.
