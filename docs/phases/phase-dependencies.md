# Phase Dependencies

## Phase 1

- Python 3.13.
- FastAPI.
- PostgreSQL.
- S3-compatible object storage.
- Redis for future queues and real-time support.
- OTP provider account.
- Basic email sender.
- Admin staff list.
- Customer level and pricing table.
- Existing ERP package and database/schema export.

## Phase 2

- Docker runtime for local infrastructure.
- Courier provider API credentials.
- Payment gateway credentials.
- GST invoice format and numbering rules.
- QR or barcode scanner.
- Label printer.
- Production machine configuration.
- Supplier contracts and price sheets.
- Confirmed ERP integration mode: database, API, library import, or file exchange.

## Phase 3

- AI artwork service provider or in-house processing model.
- Analytics warehouse or reporting database if volume requires it.
- Inventory item master.
- Maintenance schedule data.
- Dealer credit policy.
- Optional native mobile app developer account.
