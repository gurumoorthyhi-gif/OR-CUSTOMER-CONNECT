# ODD RAVEN Customer Dashboard — Codex Pack

This ZIP is prepared so you can upload the whole folder to Codex or copy the prompt from `PASTE_THIS_INTO_CODEX.txt`.

## Files
- `PASTE_THIS_INTO_CODEX.txt` — ready-to-use Codex instruction
- `UI_SPECIFICATION.md` — detailed layout, behavior and responsive rules
- `DASHBOARD_CONTENT.json` — all visible labels, sample data, routes and icon names
- `DESIGN_TOKENS.json` — colors, sizes, radius and shadows
- `FONT_GUIDE.txt` — font names and weights only
- `00_REFERENCE_DASHBOARD.png` — original reference mockup
- `icons/` — separate SVG icon files
- `assets/` — cropped visual reference elements
- `elements/` — each dashboard section converted into simple text

## Important
Font binary files are not included. Use Inter from your normal web/app dependency source or system fallback fonts.

The image crops are reference/placeholder assets extracted from the generated dashboard mockup. Replace them later with your production ODD RAVEN logo, T-shirt photos and DTF artwork if required.
